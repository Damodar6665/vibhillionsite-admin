GitHub Connect

Set this up once. Your token is stored only in this browser. Never share it with anyone.

Create a token

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Choose an expiration period (90 days is recommended) · Repository access: Only select repositories → select your website repository
  3. Permissions → Repository → Contents: Read and write (no other permissions are required)
  4. Generate the token, paste it above, then select Save & Load

How publishing works

  1. Your changes and uploaded files are sent to GitHub in a single commit.
  2. Cloudflare Pages detects the commit and deploys the site automatically, usually within 1–2 minutes.
  3. If needed, you can restore an earlier version from the GitHub commit history.
