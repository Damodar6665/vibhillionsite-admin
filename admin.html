GitHub Connect

Okkasari setup cheste chaalu. Token ee browser lo matrame save avuthundi — evvariki pampakandi.

Token ela create cheyali

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Expiration: 90 days (or your choice) · Repository access: Only select repositories → mee website repo
  3. Permissions → Repository → Contents: Read and write (inkemi avasaram ledu)
  4. Generate chesi, token ni paina paste cheyandi → Save & Load

Publish ela panichestundi

  1. Meeru chesina changes + upload chesina files anni okke commit ga GitHub ki veltayi.
  2. Cloudflare Pages aa commit chusi site ni auto-deploy chestundi — sumaru 1–2 nimishalu.
  3. Tappu jarigite GitHub commit history lo old version ki revert cheyochu.
